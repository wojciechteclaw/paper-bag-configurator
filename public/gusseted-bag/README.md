# Demo artwork of the gusseted bag (torba fałdowa)

The DEMO button with "Torba fałdowa" selected loads the client example 140 + 90 × 370 mm and these images
(list: `DEMO_CONFIGURATIONS.FOLDED.artwork` in `src/ui/demo/demoConfiguration.ts`). Missing files are skipped.

| File | Wall | Wall size (W × H or F × H) | Aspect ratio |
|---|---|---|---|
| `front.webp` | front | 140 × 370 mm | ≈ 1 : 2.64 |
| `back.webp` | back | 140 × 370 mm | ≈ 1 : 2.64 |
| `left.webp` | left gusset (full F) | 90 × 370 mm | ≈ 1 : 4.11 |
| `right.webp` | right gusset (full F) | 90 × 370 mm | ≈ 1 : 4.11 |

Each image is stretched over its wall as seen from outside (FILL). WebP, PNG or JPEG work (the file names above are
what the demo requests).
